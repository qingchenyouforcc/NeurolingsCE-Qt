# dialogs/store 商店详情

`MascotStoreDetailDialog` 展示已验证商店条目的公开元数据和摘要；对话框只读，
不触发安装或网络请求。

| 文件 | 作用 |
|---|---|
| MascotStoreDetailDialog.cc/.hpp | 主题感知的详情窗口，使用 ElaPlainTextEdit 提供可选择的描述滚动区域，并保持关闭按钮可通过键盘操作。初始尺寸由内容 `sizeHint()` 计算（常规范围约 440–640 × 320–560），并限制在屏幕可用区域内。 |

详情表面和只读编辑区的调色板会跟随 `ElaTheme::themeModeChanged` 刷新；条目文本按纯文本显示，元数据模板仍使用已转义的富文本。
描述只展示一次，避免摘要标签与正文重复；文本区域设置了合理的最小/最大高度，长描述在编辑区内滚动，较短描述不会把窗口撑出不必要的空白。
