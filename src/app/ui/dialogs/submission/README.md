# submission 投稿对话框

`MascotSubmissionDialog` 为商店页面提供已验证 `.mascot` 包的投稿表单。对话框只负责
收集公开元数据、展示本地验证/上传状态和触发 `MascotSubmissionClient`，不维护网络协议、
认证会话或包格式解析。

## 文件说明

| 文件 | 作用 |
|---|---|
| MascotSubmissionDialog.cc/.hpp | 主题感知、可滚动、高 DPI 友好的投稿表单；初始尺寸由布局内容计算并限制在当前屏幕可用区域（常规范围约 520–720 × 420–760），路径选择会在窄宽度下堆叠，输入字段和许可确认保持键盘可达，主提交按钮不设为默认按钮。 |

表单的卡片、字段调色板和按钮颜色从 `ElaTheme` 动态读取，并在主题切换信号中重新应用；上传忙碌时
输入会锁定，底部状态卡展示验证、上传和 PR 链接；用户可见文案由
`MascotSubmissionDialog` 翻译上下文提供。

内容区域始终放在 `ElaScrollArea` 中：长语言或系统字体放大时，窗口会先按布局
`sizeHint()` 计算初始大小，再按当前屏幕边界收敛，超出部分滚动而不会裁切。
卡片内容不再添加底部 stretch；短状态不会产生大块空白，字段较多时仅滚动内容区，底部关闭/提交按钮保持紧凑右对齐。
