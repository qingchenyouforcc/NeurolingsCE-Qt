# dialogs/licenses 许可证

| 文件 | 作用 |
|---|---|
| ShijimaLicensesDialog.cc | 从生成的 licenses_generated.hpp 读取文本，使用 ElaPlainTextEdit 显示只读、可搜索/滚动的许可证窗口，并在主题切换时刷新表面、字段和选区颜色；底部提供紧凑的右对齐 ElaPushButton 关闭操作。默认约 420×360，按布局内容与当前屏幕可用区域动态收敛。 |

许可证内容是构建生成物或资源的一部分，不要在此文件中手写第三方正文；依赖变更时更新生成流程。
窗口边界以当前屏幕可用几何为上限，系统字体放大或窄屏时仍保留滚动阅读，不裁切正文；正文与操作区保持清晰分组，避免额外空白。
